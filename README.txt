Para publicar no GitHub Pages:
1. Envie todos os arquivos e a pasta assets para o mesmo repositório.
2. Deixe index.html na raiz.
3. Vá em Settings > Pages.
4. Selecione Deploy from a branch.
5. Escolha main / root.
6. Salve.

Importante:
As imagens desta demonstração foram recortadas dos prints enviados para criar a apresentação comercial.
Para a versão final da cliente, o ideal é substituir pelos arquivos originais em alta resolução fornecidos por ela.
