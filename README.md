# Landing Page — FR Distribuidora

Landing page comercial responsiva desenvolvida para apresentar produtos de forma visual, rápida e orientada à conversão.

Este projeto faz parte do meu portfólio de **landing pages e interfaces front-end**, com foco em experiência mobile, organização de conteúdo, navegação simples e apresentação profissional de produtos.

## Objetivo

Transformar um catálogo tradicional em uma experiência digital mais fácil de navegar, especialmente no celular.

A página foi pensada para reduzir atrito na visualização dos produtos e permitir que o visitante encontre rapidamente o que procura.

## Principais recursos

- layout responsivo para desktop e mobile;
- navegação visual entre produtos;
- carrossel horizontal no celular;
- swipe para trocar de produto;
- setas de navegação;
- contador do item atual;
- acompanhamento automático do item selecionado;
- integração com catálogo em PDF;
- estrutura preparada para publicação em GitHub Pages.

## Foco de UX

No mobile, a experiência foi redesenhada para evitar rolagens longas e idas constantes entre lista e produto.

O usuário pode:

1. visualizar o produto em destaque;
2. trocar por swipe ou pelas setas;
3. navegar pelo carrossel de opções;
4. acompanhar qual produto está selecionado.
