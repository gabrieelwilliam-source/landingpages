DÚVIDAS RÁPIDAS

Antes de falar com o comercial

Respostas baseadas nas informações disponíveis no catálogo fornecido.

O site mostra preços?

Não. O catálogo fornecido apresenta produtos, códigos, NCM, pesos e unidades de embalagem, mas não apresenta uma tabela pública de preços. Para valores e condições, o contato é direcionado ao comercial.

Posso baixar o catálogo completo?

Sim. O botão “Ver catálogo PDF” abre o material completo usado como base para esta página.

Quais linhas aparecem no catálogo?

Há linhas de panificação, gourmet, amendoins, chopp, energéticos Pichau, água Timbu, refrigerantes Mega Refri e biscoitos Belma, além de outras variações dentro dessas categorias.

Como pedir informações de uma linha específica?

Use os botões de WhatsApp. Eles já abrem uma mensagem inicial para facilitar o contato com o comercial.
